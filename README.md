# The Banking Portal

A secure FastAPI banking backend with multi-factor authentication, password hashing,encryption at rest, and HMAC-SHA256.

---

## How to Run

### 1. Prerequisites
Make sure you have **Python 3.10+** installed on your system.

### 2. One-Click Setup
Run the automated setup script to install dependencies, drop/rebuild the SQLite database, and seed initial test accounts:

```bash
python scripts/setup.py
```
